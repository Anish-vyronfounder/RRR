# RRR Knowledge Base

Only authoritative or clearly identified sources belong here.

Priority order:
1. Manufacturer datasheets and service manuals
2. Manufacturer product specifications/support documentation
3. Standards/specifications from recognized standards bodies
4. Carefully reviewed repair references

Do not put invented specifications, AI-generated facts, or unverified forum claims here.

Each document should preserve its source filename and, for PDFs, page numbers in the ingestion metadata. RRR should answer "insufficient evidence" when the knowledge base does not support a claim.
